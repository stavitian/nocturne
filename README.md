# NOCTURNE

A collection of single-file WebGL art pieces — zero images, zero libraries,
everything rendered live in the browser. Generative WebAudio scores, no payload.

## The pieces

| Piece | File | What it is |
|-------|------|------------|
| **NOCTURNE** | [index.html](https://stavitian.github.io/nocturne/) | A living night sky — two thousand stars, a drifting nebula, shooting stars. |
| **SANCTVM** | [sanctum.html](https://stavitian.github.io/nocturne/sanctum.html) | Seven transmuting fractal geometries with a generative score. |
| **SINGVLARIS** | [singvlaris.html](https://stavitian.github.io/nocturne/singvlaris.html) | A black hole with real gravitational lensing — Schwarzschild geodesics per pixel. |
| **ARENAE** | [arenae.html](https://stavitian.github.io/nocturne/arenae.html) | Living sand — a granular automaton in a brass frame. |
| **SLOPTVM** | [sloptvm.html](https://stavitian.github.io/nocturne/sloptvm.html) | SANCTVM trimmed to three forms (menger / sierpinski / apollonian), red enlarged selector. |
| **SLOPTVM II** | [sloptvm2.html](https://stavitian.github.io/nocturne/sloptvm2.html) | Four forms (pyramid / menger / sierpinski / apollonian) with an Oxygène-style analog score. |

## Live

Everything is served from GitHub Pages:

<https://stavitian.github.io/nocturne/>

## Notes

- Single file each — no build step, no dependencies, no network fetches.
- All sound is generated procedurally with the WebAudio API (zero audio files).
- Drag to orbit, scroll to zoom, double-click for the signature action (varies per piece).
